题迹 AlgoLog 1.1.0
====================

一个完全本地运行的算法竞赛刷题记录工具。

快速开始
--------
1. 解压到一个固定文件夹。
2. 在解压后的文件夹地址栏输入 cmd 并回车。
3. 执行：
   TiJi-AlgoLog.exe --no-sandbox
4. 打开「题站管理」，添加 Codeforces、洛谷等常用网站（名称 + 网址）。
5. 想稍后做的题，先打开「待做题目」添加到清单。
6. 点击右上角「记录一题」，选择日期和题站，填写题号、题目、难度、标签。
7. 回到「总览」，用月历和年度热力图回看刷题情况。

待做题目
--------
「待做题目」是独立的清单，不会改动已有刷题记录。
点「开始做」会把题号、题目、难度和标签带入记录弹窗；
保存记录后，这道题才会从待做清单移除。取消保存则保留在清单中。

如果双击 TiJi-AlgoLog.exe 没反应，通常是因为 Windows SmartScreen
拦截了未签名程序，或者系统带有 ELECTRON_RUN_AS_NODE 环境变量。
上面的命令方式可以稳定启动。

数据位置
--------
程序目录\data\data.json
程序目录\data\backups\

数据保存在程序自己的 data 文件夹里，不再写入 AppData。
移动整个程序文件夹时，data 文件夹会一起移动，数据不会丢。
应用左下角「数据目录」可以直接打开该文件夹。
建议定期使用「导出备份」保存一份 JSON 到其他位置。

快捷键
------
Ctrl + N   快速记录一题
Ctrl + F   搜索刷题记录
Esc        关闭弹窗

不需要安装，解压后即可使用。
